# Security policy

## Reporting a vulnerability

Please report security problems privately, using GitHub's private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**. Don't open a public issue for a security problem.

Say what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Scope

In scope: the Handrail extension, meaning the code in `extension/`. For example, a page that can make Handrail run its code, read data it shouldn't, or send data out of the browser.

Out of scope: accessibility or security problems in the sites you scan. Report those to the site's owner.
